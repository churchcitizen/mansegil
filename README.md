# 전국 삼일만세길 걷기 2027

제주 조천에서 파주 임진각까지, 1919년 만세길을 51일 동안 함께 걷는 행사의 홈페이지입니다.

- 주소: https://churchcitizen.github.io/mansegil/
- 구간별 참가 신청·후원 약정·소식 받기는 서버(Supabase)에 저장됩니다.
- 관리자 모드: 페이지 맨 아래 '관리자 모드' → 계정으로 로그인 (총괄 / 지역본부장 권한)

이 저장소의 파일은 빌드 결과물입니다. 고칠 때는 원본(`기획안_산출물/스크립트/site_motion_template.html`)을 고치고
`python -I build_site_motion.py` 로 다시 만든 뒤 이 폴더를 커밋·푸시합니다.

탑골공원 사진은 실제 사진, 나머지는 시안용 AI 생성 이미지이며 현장 사진으로 교체할 예정입니다.
